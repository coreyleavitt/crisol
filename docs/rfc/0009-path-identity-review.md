## Verified correct (round 1 highlights)

- classify() total, project-first on overlap, matches lexical + realAbs (symlinked dep roots); underRoot component-boundary matching (no /proj vs /proj-extra aliasing).
- Fold/no-fold split end-to-end: ==/hash fold for membership; keyBytes/cmpKeyBytes never fold and are the sole ordering (no `<` exists on TrackedPath).
- Degraded mode: all four effects wired in lockstep on the real CLI path (pipeline narrowing gate, 3x cache gates in api.nim, saveDepGraph early return, --json evidence) — proven live by the liveness trace AND non-vacuously by test_rfc9_a_degraded.
- Liveness: all 8 RFC mechanisms trace live from CLI verbs to producers (keyBytes identity, probe->4 consumers, degraded, header mismatch discard, pcOutside consumers, rootInsideStateDir on file:// config, \\?\ via toNative on real compiles, rev-25 foldPolicy on run+list). No dark mechanisms.
- gitdiff: explicit argv (no shell), -z NUL parsing, leading-dash base-ref rejection.
- depgraph fromJson: kind-checked field access throughout, degrades to dgdMalformed, parseEnum wrapped.
- Cache filenames are 16-hex FNV digests only — no attacker-controlled path components.
- TrackedPath is a genuinely deep module: no caller re-implements canonicalization/fold/classification; tuple composition (HashSet[(TrackedPath, string)]) works via derived hash/==.
- Golden-pin suite byte-pins identityKey/slug/sidecarPath/chainedContentHash/soundnessKey incl. a depRoot vector driven through production extractClosure.
- ci/assert-subset-honesty.sh expected-skip sets checked BY NAME and consistent with the audited bucket inventory.
