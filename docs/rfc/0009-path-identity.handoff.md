## Round-1 terrain survey (the "survey" the RFC cites)

Two mapping agents swept `src/` (path-identity hazards) and `tests/` (posix coupling).

### Path-identity hazard sites (src)
- **Canonical scheme already exists but unenforced:** `closure.toProjectRelative` (closure.nim:482-506) strips root prefix + forces forward slashes — the seed of `ProjectPath.display`. `Entrypoint.path` and dep-graph keys use the same scheme.
- **`projectRoot` un-normalized at origin, re-derived 15+ times:** `config.nim` (112/154/168/937) produces `projectRoot` via bare `absolutePath` (no `normalizedPath`); `closure`/`depgraph`/`runner`/`cacheregistry`/`fnv` each recompute `projectRoot.absolutePath.normalizedPath` independently; `discover.nim:306` uses it verbatim. Feasibility measured **52 canonicalization sites across 7 modules**.
- **Equality/membership/dedup (case-fold hazards):** `narrow.nim:62/79` (`in changed` / `disjoint`) — **highest stakes**, git `core.ignorecase` vs discovery case → silent UNDER-selection; `depgraph` entry `Table[(string,string),…]`; `discover` `(relPath,group)` dedup; `closure` byBasename/byReal/`underAnyRoot`/seen-sets; `cacheregistry` underRootNorm/rootInsideStateDir. **No `sameFile`/inode primitive anywhere** — identity is always string equality.
- **Path hashing into cache keys:** `keys.identityKey`/`soundnessKey`, `planner.slug` (on-disk dir name), `cachelocalfs.sidecarPath`, `fnv.chainedContentHash` (folds relPath). None re-canonicalize.
- **POSIX/`/`-anchored assumptions:** `artifactid.eraseKnownString` (`/`-anchored, breaks on `C:`), `compilereport`/`ccprobe` (gcc/Make-shaped), `process/windows.nim` sink/cwd opened without `\\?\` long-path prefix.

## FORK DECISIONS (Corey, 2026-09-10 — "best-in-class PhD-level design"; make the call, no fake forks)
- **FORK A → ROOT-TAGGED.** Rename `ProjectPath`→`TrackedPath`. Identity = `(rootTag, rel)`; project root = tag 0, dep roots get stable tags (configured name/order). Portable+attestable by construction; kills the machine-local-abs-path-in-key wart; dissolves multi-volume. Boundary returns classification `inProject | inDepRoot(tag,rel) | outside`; distinct `NativeAbs` for byReal/underAnyRoot inputs.
- **FORK B → FULL ADDITIVE LADDER** (RFC-0007-A1 pattern). The field BECOMES the type; enforcement (un-canonicalized comparison = compile error) is the thesis. A3a-i additive (TrackedPath alongside path:string, discover produces both, invariant display==path) → migrate one surface/slice → A3a-final removes path:string via compiler-enumerated + scripted 221-site test sweep.
- **FORK C → FOLD COMPARISONS, NEVER FOLD KEYS.** Two axes of the type: (1) `==`/`hash`/membership/lookup/closure-gates FOLD under probed policy (selection soundness). (2) `keyBytes` (identityKey/soundnessKey/slug/sidecar/chainedContentHash) NEVER fold — derive from discovery's on-disk case → fleet-portable, probe-INDEPENDENT, immune to fold-induced wrong-hit. Diff case reaches ONLY membership, never a key → no inconsistency. Load-bearing property keeps its SELECTION half (mixed-case --changed selects once); the cache half becomes "same tree → same key on every host/run" (portability), NOT "warm hit across spellings". `A5` reframes from cross-spelling-hit to key-portability + no-wrong-hit.
- **FORK 3 → SCOPED OUT** (measurement/cc-probing Linux-only; RFC-0006 parked). Applied.

## (superseded) FORKS as presented for decision
- **FORK A — depRoot / multi-root identity representation.** closure legitimately tracks files under depRoots (not under projectRoot); today `toProjectRelative` falls through to a raw ABSOLUTE spelling for them (proven by `fnv.nim:68 if relPath.isAbsolute`). `ProjectPath`="project-relative" can't represent them. Options: (a) **root-tagged** `TrackedRoots{project; deps: seq[NativeRoot]}` + `ProjectPath` carries a `rootTag`, dep members key `dep:<name>/rel` (principled; fixes the machine-local-abs-path-in-attested-key wart; dissolves the multi-volume risk; renames→`TrackedPath`; NEW persisted shape for dep members → touches RFC-0005's no-reshape claim for depRoot-using projects — but those keys were never fleet-portable anyway; Linux single-root keys stay bit-identical). (b) **foreign-absolute carried forward** (compat; smaller; enshrines the abs-in-key wart, documented). **Reco: (a) root-tagged** — first-principles-correct, and depRoot abs-keys weren't meaningfully attestable. Corey owns the RFC-0005-wire-risk appetite.
- **FORK B — `Entrypoint.path` migration strategy.** Retype is whole-program-atomic (20 modules, 221 test constructions). Options: (a) **full additive ladder** (RFC-0007-A1 precedent: add ProjectPath alongside path:string, migrate surfaces one per slice, remove path:string via compiler-enumerated + scripted test sweep) — keeps the "un-canonicalized comparison = compile error" enforcement the RFC's motivation stakes on. (b) **surface-only** (keep path:string permanently as display; introduce ProjectPath only at membership/key surfaces) — much smaller blast radius, forfeits compile-time enforcement. **Reco: (a) ladder** — the enforcement IS the design's thesis (echoes ChildId/LimitKind); RFC-0007 paid exactly this cost. Corey owns the effort/risk-vs-rigor call.

Corey owns whether Windows cache-warmth-across-drift is worth the probe dependency + fleet split.
